## Test Scenarios

This Selenium automation project covers five major test scenarios on the Swag Labs application:

1. **Login with an Invalid or Locked User**
   - Attempt login using invalid or locked-out user credentials.
   - Verify that the application displays the appropriate error message.

2. **Login with a Valid User**
   - Log in using valid credentials.
   - Verify successful authentication and redirection to the Inventory page.

3. **Filter and Sort Products**
   - Sort products by Name (Descending).
   - Sort products by Price (Low to High).
   - Verify that products are displayed in the correct order after applying each filter.

4. **Add Items to the Cart**
   - Select and add at least two products to the shopping cart.
   - Verify that the selected products appear correctly in the cart.

5. **Complete the Checkout Process**
   - Proceed from the cart to checkout.
   - Enter the required billing and shipping information.
   - Complete the order and verify the successful checkout confirmation message.

**Overall Objective:** To validate the functionality of the Swag Labs application through automated testing using Selenium WebDriver and Java, covering login, product sorting, cart management, and the checkout process.
